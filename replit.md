# Trace Data · OSINT

A static front-end web app for an OSINT/digital investigation platform.

## Stack

- Pure HTML / CSS / JavaScript — no build step required
- Served with Python's built-in HTTP server

## Pages

| File | Route |
|------|-------|
| `index.html` | `/` — Landing page |
| `login.html` | `/login.html` — Login |
| `register.html` | `/register.html` — Register |
| `dashboard.html` | `/dashboard.html` — Dashboard |
| `profile.html` | `/profile.html` — User profile |
| `docs.html` | `/docs.html` — Documentation |
| `faq.html` | `/faq.html` — FAQ |
| `privacy.html` | `/privacy.html` — Privacy policy |
| `terms.html` | `/terms.html` — Terms of service |

## How to run

The **Start application** workflow serves all files on port 5000:

```
python3 -m http.server 5000
```

No dependencies to install.
